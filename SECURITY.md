# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Please report suspected security vulnerabilities (such as path traversal, arbitrary file overwrite, or denial of service via crafted binary/compressed headers) privately using GitHub Private Vulnerability Reporting:

https://github.com/SuzumiyaHaruhi719/chrcheck/security/advisories/new

Please include a minimal reproduction input and expected vs. actual behavior. Do not disclose vulnerability details in public issues before a fix is released.
